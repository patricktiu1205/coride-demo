# 🚀 CoRide——Robotaxi 时代的出行体验聚合平台

> **命题赛道：09 AI+综合交通**  
> CoRide 在 Robotaxi 运营商与用户之间构建 AI 体验层：一个 App 跨运营商叫车，个人 Agent 记住你的偏好，上车即用、下车即拆。
>
> 🔗 **在线 Demo**：[patricktiu1205.github.io/coride-demo](https://patricktiu1205.github.io/coride-demo/)

---

## 一、项目简介

2026 年，广州至少 4 家 Robotaxi 运营商同时运行，但 72% 用户拒绝乘坐——不是技术问题，是信任问题。当 L4 自动驾驶在五年内成为标配，"谁开得好"不再构成竞争壁垒。然而产业中 90% 的投入去了"车怎么开"，**"车里的人由谁来服务"成了无人认领的盲区。**

CoRide 参考高德打车聚合模式，接入多家 Robotaxi 运营商，同时构建**个人 Agent 记忆引擎**：用户偏好加密托管，上车通过蓝牙 5.0 临时传输至车端 Jetson 外挂盒（自有无主控安全风险），下车立即清除。偏好跟人走，不跟车走——用户换任何一辆 Robotaxi，座舱都一样"认识"你。

核心能力：**聚合叫车**（一个 App 跨运营商）、**个性化 Agent**（跨车偏好跟随、驾驶解释、语音对话、舱内视觉）、**隐私优先**（图像不出车、语音不上云、偏好下车即擦）。

## 三、系统架构

```
📱 手机瘦客户端（零 AI 模型 · 零偏好落盘）
  ↓ 🔵 蓝牙 5.0 AES-256 — 偏好包 < 50KB
🚗 Jetson Orin Nano 外挂盒（全 AI 推理本地完成）
  · SLM 推理 Qwen2.5-7B INT4 · 语音管线 < 1.5s
  · YOLOv8-Nano 30FPS 舱内视觉 · CAN 只读驾驶+读写舒适
  ↓ 🟢 TLS 1.3 — 仅脱敏日志上传
☁️ CoRide 云端平台
  · BGE-M3 偏好向量嵌入 1024d · Qdrant P99 < 10ms
  · RAG 上下文注入 · Qwen2.5-72B LLM 兜底 (< 3% 请求)
  ↓ 🟠 RESTful API — 派单指令
🏢 运营商车辆接入层
  小马智行 · 文远知行 · 滴滴自动驾驶 · Apollo 等
```

> 🔒 **安全边界**：图像不出车 · 语音不上云 · 偏好下车即擦 · 身份脱敏
