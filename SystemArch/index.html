📱 手机端架构详解 — 瘦客户端设计
📋 用户流程六步
1
注册
手机号一键注册，绑定支付方式，无需KYC
2
叫车
输入目的地 → 云端匹配 → 多运营商比价返回
3
Agent 比价
聚合4家运营商报价，按价格/等待时间/评分排序
4
蓝牙握手
上车自动蓝牙连接 → AES-256加密传输偏好包 → 下车安全擦除
5
外部确认
下车前弹窗确认：遗失物品检查 / 行程评价预填
6
评价
五星评分 + 标签评价，反馈至云端偏好模型
🔐 安全与隐私设计
🔒
蓝牙 5.0 握手
上车自动配对，无需手动操作。偏好包 <50KB，AES-256加密传输，<200ms完成
🗑
下车安全擦除
行程结束自动清除车端偏好缓存。手机不存任何车辆数据，车端不存任何用户身份信息
📵
行程中静默
手机不参与车内语音交互。所有语音处理在 Jetson 本地完成，不依赖手机算力
⚡ 为什么是瘦客户端？
📱
零算力依赖
不运行任何模型，不消耗手机GPU/CPU。适配千元机，覆盖全价位用户
🔋
超低功耗
仅蓝牙传输 + UI渲染，行程中耗电 <2%。不装模型 = 不费电
🛡
隐私最优
偏好数据加密传输，车端临时缓存，下车即擦。手机不留行程痕迹
🚗 Jetson Orin Nano 车端详解
🧠 SLM 推理引擎
模型Qwen2.5-7B-Instruct
量化INT4 (Q4_K_M)
推理延迟<300ms / token
内存占用~5.2GB VRAM
吞吐15-20 tokens/s
上下文8K tokens
能力矩阵
🗣
语音对话
SenseVoice → SLM理解 → CosyVoice合成。端到端延迟 <1.5s，支持打断
📖
驾驶解释
解读CAN信号，用自然语言解释车辆行为：「正在减速，前方200米右转」
🎯
偏好检索
从蓝牙传入的偏好包中快速匹配：温度、音乐、座椅。本地FAISS索引，<50ms
👁 视觉感知模块
模型YOLOv8n (Nano)
帧率30 FPS
推理延迟<15ms / 帧
检测类别人/包/手机/钥匙
精度mAP@0.5: 92%
数据本地处理，不出车
三大检测场景
🎒
遗留物检测
乘客下车后扫描座位，检测手机/包/钥匙。发现遗留物触发告警+提醒
🧍
乘客姿态
识别乘客是否系安全带、是否在座椅上。异常姿态触发安全提醒
🔢
人数计数
上下车人数自动统计，超员告警。辅助运营数据采集
